1. Case Study / Point of View

Executive Summary

We built a general-purpose, AI-orchestrated test automation framework using Kiro and Playwright that automates functional testing for any web application. The framework converts requirements — from Jira tickets, user stories, or documents — into working, self-healing automated tests in minutes rather than days.

To prove its capability, we applied it to one of the hardest automation targets in the industry: a Salesforce Experience Cloud application. If the framework can handle Salesforce's complex Shadow DOM, it can handle virtually any web application.

The Problem (Universal Across Web Apps)

ChallengeImpact
Manual test authoring1–2 days per user story
Complex DOM (SPAs, Shadow DOM, iframes)Standard locators fail to find elements
Locator fragilityTests break with every UI change
Fragmented toolingRequirement → test involves 5+ manual handoffs
Maintenance burden60%+ of automation effort spent fixing broken tests

The Solution

An AI-orchestrated pipeline where Kiro acts as the automation engineer:

  1. Reads the requirement — from Jira, a document, or chat
  2. Creates test cases — in Zephyr Scale, linked to the source
  3. Generates the feature file — business-readable Gherkin
  4. Discovers locators live — Playwright MCP navigates the real app, pierces Shadow DOM, and verifies each locator by interacting with it
  5. Builds the automation — Page Object + test spec following POM best practices
  6. Runs and self-heals — executes the test; if a locator breaks, it re-inspects the live page and fixes itself
  7. Reports back — posts results on the Jira ticket

Key Innovation: The Self-Healing Locator

The breakthrough is not generating code from guesswork — it's navigating the live application to discover and confirm locators.

4. Workflow Walkthrough

Overview of the 4 Workflows

#WorkflowTriggerJiraZephyrAutomates
1Jira Automation"Automate KD-7"—✓✓
2User Story AutomationPaste story / doc——✓
3Story → Jira → Zephyr → Test"Create in Jira and automate"✓✓✓
4Test Execution & Reporting"Run smoke tests"——Runs existing

Workflow 1: Automate from Jira

1. Read Jira ticket          → getJiraIssue
2. Create Zephyr test cases  → linked to ticket
3. Generate feature file     → Gherkin with tags
4. Discover locators         → Playwright MCP healer (live page)
5. Build Page Object         → extends BasePage
6. Write test spec           → uses fixtures
7. Run & heal                → execute, fix, re-run
8. Post Jira comment         → results summary

Workflow 2: User Story to Automation

Paste a requirement in chat or attach a Word/PDF document. Kiro parses it, structures a user story, then generates the feature file, discovers locators, builds the Page Object, writes the test, and runs it. No Jira needed.

Workflow 3: Story → Jira → Zephyr → Automation

The most comprehensive flow. Kiro creates a new Jira ticket, creates Zephyr test cases linked to it, generates the feature file, automates the test, runs it, and posts results back on the ticket — all from a single conversation.

Workflow 4: Test Execution & Reporting

npx playwright test --project=chromium --grep @smoke
npx playwright test --project=chromium --grep @regression
npx playwright test --project=chromium --grep @e2e

Runs the suite, collects results, generates a structured report, and optionally posts to Jira.

Setup Guide

# Install
cd ai-test-framework
npm install
npx playwright install chromium

# Configure src/config/.env.dev
BASE_URL=https://your-application-url
APP_USERNAME=your-username
APP_PASSWORD=your-password
Note: Use APP_USERNAME/APP_PASSWORD (not username/password) to avoid conflict with Windows system environment variables.

Running Tests

npm run test:smoke
npm run test:regression
npm run test:e2e

# Specific spec
npx playwright test src/playwright/tests/smoke/incident-creation.spec.ts --project=chromium

Security Considerations

  • Kiro runs locally — code never leaves your machine
  • Credentials in .env files (gitignored)
  • Use sandbox environments only — never production
  • Use synthetic test data — never real customer PII
  • Rotate PATs (Jira, Zephyr) regularly
