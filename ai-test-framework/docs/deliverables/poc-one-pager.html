AI Test Automation Assistant

An AI-orchestrated solution that turns Azure DevOps work items into working automated tests. Kiro reads the user story, generates linked manual test cases, authors Gherkin features, discovers and self-heals live UI locators, builds the Page Object and test, then runs it and posts results back to the work item — delivering traceable, end-to-end coverage with minimal human effort.

⚙

Client's Challenge

Test creation was manual, slow, and hard to keep in sync with requirements.

  • Authoring cases and scripts from each work item took hours per story.
  • Fragile UI locators broke often on the Salesforce/Shadow-DOM app.
  • Weak traceability between requirements, test cases, and automation.
  • Results lived in tooling silos, not on the work item.
  • Limited regression coverage under tight sprint timelines.
🛠

Milestone Solution

A Kiro-driven pipeline that automates the full lifecycle from work item to green test.

  • Reads the ADO work item and derives the full test-scenario set.
  • Creates linked manual Test Cases (Child) for traceability.
  • Generates tagged Gherkin feature files from acceptance criteria.
  • Discovers & self-heals live locators (pierces Shadow DOM).
  • Builds Page Objects + Playwright specs to framework standards.
  • Runs headed, heals failures, and comments results on the work item.
📈

Value Delivered

Automation shifts from manual, one-off scripting to scalable, traceable coverage.

  • Work item to executable test in minutes, not hours.
  • Every test traces to a requirement and Test Case ID.
  • Self-healing locators cut maintenance and flaky failures.
  • Results posted back to Azure DevOps for a closed loop.
  • Consistent Page Object Model across the suite.
  • Faster, broader regression within the sprint.
