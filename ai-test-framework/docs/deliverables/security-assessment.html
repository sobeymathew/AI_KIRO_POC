What's Safe ✅

  • Kiro runs locally in your IDE — code doesn't leave your machine
  • Playwright tests run on your browser on your local machine
  • .env credentials are never uploaded to any AI service
  • MCP servers run locally using your tokens (stdio transport)
  • No production data accessed — we use sandbox/test environments only
  • No data transmission to third-party servers beyond configured MCP endpoints

What to Watch ⚠️

  • Don't paste real PII (policy numbers, SSNs, customer names) in chat — use test data
  • Don't share PATs/tokens in conversation history
  • Credentials in .env files must be in .gitignore
  • Use sandbox/test environments only — never point automation at production
  • Rotate tokens regularly (Jira, Zephyr, Azure DevOps, GitHub)

Bottom Line

For test automation against a sandbox environment with synthetic data — Kiro is safe.

The risk comes from human behavior (pasting secrets, using real data) rather than the tool itself. All processing is local, all connections are authenticated via HTTPS, and no data is transmitted to AI cloud services.
